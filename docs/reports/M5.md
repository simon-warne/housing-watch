# M5 report, part A: Bostadsförmedlingen reconnaissance (2026-11-26)

## Done
- **Access:** 9 GETs, logged out, 5 s apart ([request log](evidence/M5-requests.log)). No robots.txt (404); no site terms page found; BF's rules (`/sa-gar-det-till/regler/Regler/`) say nothing about automated reading.
- **Listings:** `GET /AllaAnnonser/` returns **all 527 listings in one JSON array** (700 KB): id, district (`Stadsdel`), municipality, address, floor, rooms, size, rent, advertised from/to, type (`Lagenhetstyp`: Hyresrätt 365, Studentlägenhet 77, UngdomKorttid 26, Ungdomslägenhet 21, Korttidskontrakt 21, Studentkorridor 6, …) and flags (`Student`, `Ungdom`, `BostadSnabbt`, `Korttid`, …). 130 are student or youth, 31 of them ≤ 6,000 kr. Move-in is **not** in the list (null on all).
- **Detail page** (`/bostad/<id>/`, HTML): Inflytt (a date, or text like "januari 2027" / "så snart som möjligt"), **Anmälan senast** (date only, no time), landlord conditions (youth: age 18–25, income ≥ 285,000 kr), and, logged out, **"Längsta anmälda kötider på denna bostad"**: the queue start dates of the top 3 applicants. This is BF's version of SSSB's top days. Bostad snabbt pages have no such block.
- **Rules:** every listing goes by queue time; tie → whoever applied first. Bostad snabbt = hard-to-let flats, queue time kept. Student flats and short-term contracts keep queue time; a permanent contract resets it. **Two declines ("avhopp") within 6 months block applying for 3 months.**
- **Fixtures:** `tests/fixtures/bf/` (list + student, youth, Bostad snabbt details) with a README.

## Proposed design for part B (needs Simon)
- One list request per run plus detail pages for matching listings only (move-in, deadline, top-3 dates), chosen by public facts, ≤ 10 per run, as for SSSB.
- **Winnable** = my BF queue start date is earlier than the top applicant's (same date → "tied"). Bostad snabbt → "first come" alert. Same alert kinds as SSSB, tagged `BF`, in the same digest.
- With a queue start of Nov 2026, few BF listings will be winnable for a year or more (top dates seen: 2020–2021). The value now is the data (and the odd listing with few applicants: third-longest date seen was 2026-11-09).
