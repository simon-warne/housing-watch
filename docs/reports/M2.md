# M2 report: history and changes (2026-11-26)

## Done
- `src/housing_watch/history.py` (stdlib `sqlite3`):
  - `open_db(path)`: creates the schema if it's missing; schema v1 via `user_version`; never wipes data.
  - `record(conn, listings, details, seen_at) -> Changes`: returns new, changed `(old, new)`, removed and unchanged. One transaction per run.
  - `latest(conn, id) -> Listing | None` and `deadline(conn, id) -> datetime | None`.
- Tables:
  - `listings`: id, first_seen, removed_at.
  - `observations`: one row per distinct state, deadline included.
  - `alerts`: empty until M3. A unique dedupe index on `(listing_id or '', kind, state_key)`.
- **Change-only observations** (your approval, logged): if a run sees no change, the DB file stays byte-identical.
- **Empty-list guard:** 0 listings → nothing written, nothing removed.
- **Deadline:** when a run doesn't fetch the detail page, the last known deadline carries forward. A listing that comes back after removal starts with no deadline.
- All times are stored as UTC ISO strings, so the same page never looks "changed".
